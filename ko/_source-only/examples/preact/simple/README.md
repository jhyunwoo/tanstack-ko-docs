## 시작하기

- `pnpm dev` - http://localhost:5173/에서 개발 서버를 시작합니다.

- `pnpm build` - 프로덕션용 빌드, `dist/`로 방출

- `pnpm preview` - http://localhost:4173/에서 서버를 시작하여 로컬에서 프로덕션 빌드를 테스트합니다.
