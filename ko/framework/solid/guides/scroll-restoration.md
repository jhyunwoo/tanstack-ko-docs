id: scroll-restoration
title: 스크롤 복원
---




일반적으로 웹 브라우저에서 이전에 방문한 페이지로 이동하면 해당 페이지에서 다른 곳으로 이동하기 전의 정확한 위치로 페이지가 스크롤되는 것을 볼 수 있습니다. 이를 **스크롤 복원**이라고 하며 웹 애플리케이션이 클라이언트 측 데이터 가져오기 방향으로 이동하기 시작한 이후로 약간 퇴보했습니다. 그러나 TanStack Query를 사용하면 더 이상 그렇지 않습니다.

TanStack Query는 스크롤 복원 자체를 구현하지 않지만 SPA에서 복원이 중단되는 가장 큰 원인 중 하나인 다시 가져오기로 인한 UI 재설정을 제거합니다. 이전에 가져온 데이터를 캐시에 보관하면(선택적으로 `placeholderData` 사용) 페이지로 돌아가는 탐색이 안정적인 레이아웃으로 즉시 렌더링될 수 있으므로 라우터(예: TanStack Router의 스크롤 복원 또는 소규모 사용자 정의 기록 기반 솔루션)에서 처리할 때 스크롤 복원을 안정적으로 수행할 수 있습니다.

TanStack Query의 모든 queries(페이지가 매겨진 무한 queries 포함) Just Works™️에 대해 기본적으로 "스크롤 복원"이 가능합니다. 그 이유는 query 결과가 캐시되어 query가 렌더링될 때 동기적으로 검색될 수 있기 때문입니다. queries가 충분히 오랫동안 캐시되고(기본 시간은 5분) 가비지 수집되지 않는 한 스크롤 복원은 항상 즉시 작동합니다.
