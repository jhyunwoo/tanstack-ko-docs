Vue Query의 가져오기 메커니즘은 Promise를 기반으로 구축되었으므로 GraphQL을 포함한 문자 그대로 모든 비동기 데이터 가져오기 클라이언트와 함께 Vue Query를 사용할 수 있습니다!

> Vue Query는 정규화된 캐싱을 지원하지 않는다는 점에 유의하세요. 대다수의 사용자는 실제로 정규화된 캐시가 필요하지 않거나 생각만큼 많은 혜택을 누리지 못하지만, 이를 보증할 수 있는 매우 드문 상황이 있을 수 있으므로 먼저 당사에 문의하여 실제로 필요한 것인지 확인하십시오!
