[NPM](https://npmjs.com)을 통해 Svelte Query를 설치할 수 있습니다.

### NPM

```bash
npm i @tanstack/svelte-query
```
또는

```bash
pnpm add @tanstack/svelte-query
```
또는

```bash
yarn add @tanstack/svelte-query
```
또는

```bash
bun add @tanstack/svelte-query
```
> 다운로드하기 전에 한번 사용해 보고 싶으신가요? [create-svelte](examples/basic.md) 예제를 사용해 보세요!
